# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.1] - 2026-10-11

### Added
- Multi-plugin support with organized `src/plugins/` directory
- `src/index.js` entry point for loading all plugins
- Hello World example plugin (`src/plugins/helloWorld.js`)
- Test suite with Jest configuration
- `.gitignore` for common exclusions
- Comprehensive installation guide in README
- Troubleshooting section

### Changed
- Converted all documentation to English
- Refactored repository structure to support multiple plugins
- Improved README with better organization and examples

### Security
- Apache 2.0 license
- Secure plugin architecture
